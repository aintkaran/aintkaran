## Portfolio

My photography portfolio lives at [aintkaran.vercel.app](https://aintkaran.vercel.app/). It opens with a short rolling-word intro (Design, Photography, Product, aintkaran) and then a horizontal looping gallery. Reduced-motion settings skip the intro.

It runs on two repositories:

- [website3](https://github.com/aintkaran/website3): the static front end and generated image exports, deployed on Vercel.
- [originals](https://github.com/aintkaran/originals): the source photos, metadata and the sync pipeline that generates the exports.

Both READMEs list the open source libraries and fonts the site and pipeline use, with sources and licenses.
